# Lab 5 CI evidence

The three run reports are generated by the `lab5-ci` GitHub Actions workflow after
the build and smoke jobs pass. Download the `lab5-report` artifact from a successful
run on `main`, then extract `report.json`, `report.md`, and `run-view.md` here.

Do not replace run IDs or URLs with placeholders: the DevOps collector checks that
these files describe the same real run.
